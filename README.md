# Online-Testing-Platform-Project

MCS 2026 spring – fall project

## Технологии

**Фронтенд:** React + TypeScript + Tailwind
**Бэкенд:** Python + Django
**БД:** PostgreSQL
**Хранение файлов:** Локально
**Авторизация:** JWT
**Контейнеризация:** Docker

## Первый этап

На первом этапе реализуем минимальный MVP: пользователь уже считается авторизованным, открывает сайт, видит список готовых тестов, выбирает один тест, проходит его и получает результат.

Подробные задачи первого этапа зафиксированы во вкладке **Projects**.

## План реализации (спринты)

### Весна

1. Работающий docker-compose; можно зарегистрироваться, войти, получить JWT; прототипы в Figma
2. Учитель авторизовался, видит список своих тестов, может создать минимальный (название + время) тест, может редактировать и удалять тест
3. Учитель может добавить вопросы в тест (вопросы с одним правильным ответом), список вопросов отображается, их можно изменить, данные сохраняются в БД
4. Студент может пройти тест, получить баллы

**Итог весны:** Учитель регистрируется, создаёт тест с вопросами, студент регистрируется, видит тест, проходит его, получает баллы.

### Осень

5. Полная интеграция frontend и backend без mock-данных. Список тестов, данные конкретного теста, отправка ответов и получение результата работают через реальный API.
6. История прохождения тестов. Пользователь может просматривать свои предыдущие попытки и результаты.
7. Публикация и скрытие тестов. Преподаватель может управлять доступностью тестов, студент видит только опубликованные тесты.
8. Поддержка вопросов с несколькими правильными ответами. Студент может выбирать несколько вариантов, backend корректно проверяет их и учитывает при подсчёте результата.
9. Таймер управляется сервером, по истечении времени тест автоматически завершается.
10. OAuth2, минимальный прокторинг вида: нельзя переключаться между вкладками, сворачивать окно, копировать текст вопроса и т.д.
11. Автоматизировать тестирование, сборку, ловить ошибки.
12. AWS S3, кэширование Redis.
13. Документация, финальное тестирование.
