# Online-Testing-Platform-Project
MCS 2026 spring – fall project

## Технологии

**Фронтенд:** React + TypeScript + Tailwind  
**Бэкенд:** Python + Django  
**БД:** PostgreSQL  
**Хранение файлов:** Локально  
**Авторизация:** JWT  
**Контейнеризация:** Docker  

### Осенью добавить:
- Redis + Celery для эффективности  
- WebSockets для более интересной работы со временем  
- OAuth2 для более интересной авторизации  
- AWS S3 для масштабирования сервиса  

---

## План реализации (спринты)

### Весна

1. Работающий docker-compose; можно зарегистрироваться, войти, получить JWT; прототипы в Figma  
2. Учитель авторизовался, видит список своих тестов, может создать минимальный (название + время) тест (и он появится в списке), может редактировать и удалять тест  
3. Учитель может добавить вопросы в тест (вопросы с одним правильным ответом), список вопросов отображается, их можно изменить, данные сохраняются в БД  
4. Студент может пройти тест, получить баллы.  

**Итог весны:** Учитель регистрируется, создаёт тест с вопросами, студент регистрируется, видит тест, проходит его, получает баллы.

### Осень

5. Добавляем администратора (он может управлять всеми сущностями); студент видит только доступные ему тесты, учитель только свои, админ – все. Соответственно тесты можно скрыть / опубликовать.  
6. Таймер управляется сервером, по истечении времени тест автоматически завершается.  
7. Появляются вопросы с открытыми ответами. Учитель проверяет их самостоятельно, студент получает уведомление.  
8. Учитель может получить отчёт с ответами студентов, есть статистика по тесту, экспорт не блокирует интерфейс.  
9. OAuth2, минимальный прокторинг вида: нельзя переключаться между вкладками, сворачивать окно, копировать текст вопроса и т.д.  
10. Автоматизировать тестирование, сборку, ловить ошибки.  
11. AWS S3, кэширование Redis.  
12. Документация, финальное тестирование.
