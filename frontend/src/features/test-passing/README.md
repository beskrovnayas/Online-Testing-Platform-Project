# Прохождение теста

`TakeTest.tsx` — страница прохождения. `usePassingAttempt.ts` управляет ответами, отправкой и завершением по времени. `TestResultDetails.tsx` показывает баллы и ответы, полученные от сервера.

Запросы идут в `http://localhost:8000/api` с JWT:
- `GET /tests/{id}/` — данные теста;
- `POST /submit-answers/` — отправка ответов и получение результата.

Ответы, срок завершения и результат сохраняются в `sessionStorage` для текущего пользователя и вкладки.

Для подключения истории используется `VITE_ATTEMPT_DETAIL_PATH`, для запуска серверной попытки — `VITE_TEST_START_PATH`. Эти API пока отсутствуют; без API запуска время отсчитывается в браузере. Выбор нескольких вариантов в интерфейсе пока недоступен.
